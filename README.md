# Vancouver Style Karolinska Institutet Flavor

The center of this repo is a ".csl"-file (Citation Style Language file). This file is dedicated to import as a citation style in the Zotero App for collecting and managing citations. This style is based on Vancouver Style with some modifications for Karolinska Institutet and the Swedish Laws Reference Style.

## Files

- `vancouver_karolinska_institutet_flavor.csl` - Standard Vancouver numbering: `(1)` in text and `1.` in the reference list
- `vancouver_karolinska_institutet_flavor_sqrd.csl` - Square-bracket numbering: `[1]` in text and `[1]` in the reference list

Both files provide the same citation fields and formatting features. Choose the version whose numbering format matches your requirements.

## Usage

1. Download either CSL file, depending on your preferred numbering format
2. In Zotero, go to Edit → Preferences → Cite → Styles → "+" (add style)
3. Select the downloaded CSL file to install the style

## Features

- Based on Vancouver citation style (numeric citations)
- Supports standard Vancouver numbering or square-bracket numbering, depending on the selected file
- Adapted for Karolinska Institutet requirements
- Support for Swedish Laws Reference Style
- Bilingual support (English and Swedish terms)
- **Software, Applications, and AI Tools support** (Computer programs, Mobile applications, Large language models, Text-to-image models)
- **Dataset support** with `[dataset]` labeling and DOI-preferred identifiers
- **Medium field support** for specifying item types (replaces [Internet] with specific medium)
- **Enhanced identifier handling** with priority: DOI → PMID → ISSN → URL for articles; ISBN → URL for books
- **Extra field support** for Figure/Table/Image references with page numbers
- Version abbreviation as "ver."
- Edition abbreviation as "ed."
